## Why this verdict and not the adjacent one

Not **partial**, with one nuance stated: in Cargo semantics a bare `"1.1.2"` is a
caret requirement (`^1.1.2`), not the strict `= "1.1.2"` form — if a newer
compatible release were published, a `cargo update` could float past 1.1.2. Three
things keep this at implemented rather than partial: (a) the manifests state the
version 1.1.2 verbatim, which is the plain reading of "pin exactly 1.1.2" in the
holds-if clause; (b) the committed `Cargo.lock` resolves both crates to exactly
1.1.2, so actual builds are exact; (c) the appendix's own note for this row is
"Latest 1.1.x" (IMPLEMENTATION_APPENDIX.md L21), which endorses caret-style
tracking of the 1.1 line rather than demanding `=`-syntax. The `Anchor.toml`
toolchain pin is exact with no caveat.

Not **stronger-than-spec**: the code does exactly what the row asks, no more.
