# REQ-15 — CUSTODIAN is a compile-time constant (HxwZ)

## Requirement (verbatim)

From `/home/david/claude/thugbirdz/IMPLEMENTATION_APPENDIX.md` §2, Seeds (line 113):

> `pub const CUSTODIAN: Pubkey = pubkey!("HxwZCEMgck9v24iP9y2YcBttBkM7GjX77oBiNmQYiiUB");`

Surrounding appendix rationale (lines 110–112):

> // Deposit source owner; fix_mapping and recover destination. A compile-time constant,
> // deliberately — an init-time field could be mis-set to admin, which would put admin
> // back in the destination seat. The verified build pins this to the reviewed source.

Holds if: CUSTODIAN is a compile-time constant equal to
`HxwZCEMgck9v24iP9y2YcBttBkM7GjX77oBiNmQYiiUB`, not an init-time field.

## Verdict

**implemented** — confidence **high**.

## What the requirement demands

1. A `const` named CUSTODIAN of type `Pubkey`, resolved at compile time (not read
   from an account, instruction data, or set during `initialize_pool`).
2. Its value in the production (default-features) build is exactly the HxwZ key.
3. No parallel init-time channel (a `custodian` field on `Pool`, or a `custodian:
   Pubkey` instruction argument) that could override or substitute for the constant.

## Where enforcement lives

`program/programs/thugz-swap/src/constants.rs` L19–L24:

```rust
#[cfg(not(feature = "test-keys"))]
#[constant]
pub const CUSTODIAN: Pubkey = pubkey!("HxwZCEMgck9v24iP9y2YcBttBkM7GjX77oBiNmQYiiUB");
#[cfg(feature = "test-keys")]
#[constant]
pub const CUSTODIAN: Pubkey = pubkey!("FmsQWrqdWwvjREEB1CmD7w1hrzz2coXq8SxxAj9bLQZZ");
```

The default (`not(feature = "test-keys")`) arm is a `pub const` initialized with the
`pubkey!` macro — a compile-time constant — equal byte-for-byte to the key the appendix
names. The `#[constant]` attribute exports it to the IDL, which the appendix (L140–144)
requires and `program/scripts/verify_mainnet_artifact.py` checks (L31, L42–43, L48:
bytecode must contain HxwZ, must not contain the test key, IDL `CUSTODIAN` must equal
HxwZ).

The `test-keys` arm substitutes a committed fixture key. That substitution is itself
specified by the same appendix section (L136–138): "A `test-keys` cargo feature swaps
ADMIN/CUSTODIAN for committed fixture keypairs … **The mainnet artifact is the
default-features build**". So the cfg-gated second arm is spec-conformant, not a
deviation.

## Why this verdict and not the adjacent ones

- Not **partial**: the only alternate value is behind the `test-keys` feature, which
  the requirement's own source document defines and which the deploy guard
  (`verify_mainnet_artifact.py` L42–48) blocks from mainnet. Every runtime path in the
  default build sees the HxwZ constant.
- Not **stronger-than-spec**: the `#[constant]` IDL export and the artifact guard are
  also demanded by the same appendix section (L140–144), so they are compliance, not
  extra enforcement.
